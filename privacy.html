나의 오피스 개인정보처리방침

수집하는 정보

앱은 서버로 어떤 정보도 보내거나 저장하지 않습니다. 사용자가 입력한 기록(건강·마음·공부 기록 등)은 모두 사용자의 휴대폰 안에만 저장됩니다.

Google 사용자 데이터

사용자가 구글 계정을 연결하면 다음 정보를 읽기 전용으로 가져옵니다: Google 캘린더 일정(생일·기념일·공휴일 포함), Google 할 일(Tasks). 이 정보는 앱 화면에 일정 브리핑으로 보여 주는 목적으로만 사용하며, 휴대폰 밖으로 전송하거나 제3자와 공유하지 않고, 광고에 사용하지 않습니다.

이 앱의 Google API 정보 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

연결 해제

앱을 삭제하거나 구글 계정의 서드 파티 연결 관리에서 '나의 오피스'를 삭제하면 접근 권한이 사라집니다.
